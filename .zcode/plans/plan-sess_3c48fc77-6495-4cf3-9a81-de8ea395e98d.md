## Fix Folder Click Slowness
The folder filter click is slow because it causes a full navigation and refetches from the database **without showing a loading skeleton**. The stale grid remains frozen until the network request completes, creating a "laggy" feel. Also, the app performs a redundant double-filter (both in the Supabase query and in React memory).

1. In `src/app/(app)/captures/page.tsx`:
   - Add `setLoading(true)` to the start of the fetch effect. This will instantly hide the stale grid and show the `animate-pulse` skeletons the moment a folder is clicked, making the UI feel instantly responsive.
   - Remove the redundant `workspaceCaptures` client-side array filter. The data is already strictly filtered by the Supabase `.eq("folder_name", ...)` query on the server.
   - Keep the client-side search/type/tag filters intact.

This is a fast 3-line fix that instantly improves responsiveness.
